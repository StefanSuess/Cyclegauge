# Version history

Bobert was formerly called Cyclegauge. Earlier history lives in the archived Cyclegauge repository; the full list of changes is in [CHANGELOG.md](../CHANGELOG.md).

## Release summary

- **1.0.0** First release under the name Bobert (macOS, Windows, Ubuntu); not yet published.
  - Budget warnings, a modelled overage cost with a next-plan comparison and a plan right-sizing hint, and an interactive dashboard with cycle comparison, results summary, cycle recap and CSV export.
  - A workspace audit grouped by suggested action, with a Steering and Hooks review, previewed edits that you review and save, and session hints (observed on macOS; enabled on Windows and Linux but not yet verified natively).
  - A first-minute walkthrough, Report a Problem with fixed-codes diagnostics, and an "update needed" message with a storage migration path. Settings and history from Cyclegauge are not carried over.
