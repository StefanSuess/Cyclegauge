# WP6e cycle recap, image save, copy text and CSV export validation

Phase 6e adds the dismissible "Your Kiro cycle" card to the credit view, **Save image…**, **Copy text**, **Dismiss** and **Export CSV…**, and the persisted key `cyclegauge.recap.v1`. The first section of this page lists what the phase does, the second what was verified, the third what is still open.

What it does. **Recap definition** (`recap.ts`, pure): the card describes the cycle before the newly observed one and appears only when that cycle has an evidence-backed start and end (the current cycle starts at its reset time) and an unbroken counter chain from the start (the rule the cycle comparison already uses); otherwise there is no card. It shows credits used of the reported limit as of the last update; "lasted until the reset" as *no* when usage at or above the limit was observed, *yes* when an update below the limit lies within 6 hours before the reset, otherwise *unknown*; the average credits per day over the observed part of each cycle against the cycle before (exact decimals, or "not observed" / "not comparable" for a missing start, an adjustment, a conflict or a limit change); the exclusions saved in that cycle from `cyclegauge.results.v1` (or "none counted" / "not available"); and the busiest UTC day from same-day evidence intervals only, labelled "busiest observed day (partial observation)". The Open VSX link is plain text and follows the existing `cyclegauge.supportPrompts` switch (no new setting). **State**: `cyclegauge.recap.v1` is `{ cycle, state: 'shown' | 'dismissed' }`, strictly validated, written by a queued fail-silent writer, never overwritten when unknown, newer or already dismissed, not registered for Settings Sync, and cleared by the existing reset command (title unchanged). **Messages**: `exportCsv`, `copyRecapText`, `saveRecapImage { png }` (base64 text up to 2 MB, the one exception to the 4 KB cap) and `dismissRecap` go through `acceptMessage` with exact keys, Map dispatch, one in flight per type (including while a save dialog is open), a 2 s cooldown per type, the global 10 messages per second and the rejected counter; the script sends them only from trusted clicks and the host answers with a fixed code. **Writes**: only after the editor's save dialog, `file:` targets only, with the real location (parent resolved natively, final name checked, case folded on macOS and Windows) outside Cyclegauge storage, configured and default Kiro source folders, `~/.kiro` and any folder named `.kiro` or `kiro-cli`, no symlinks or special files, an exclusive temporary file in the checked folder renamed over the target and removed on failure. **PNG**: the script re-encodes the drawn pixels into exactly IHDR, one IDAT and IEND; the extension accepts only that shape (fixed 1200 x 630 RGBA, every CRC, no other chunk, inflation capped at the exact raw size, no bytes after the zlib stream or IEND). **CSV**: one associated account only; allowlisted columns, exact decimals, `unknown` for missing values, no free text, identifier or partition key, conflicting same-time snapshots all exported with a conflict flag.

Protected folders for every write (compared by real location, case folded on macOS and Windows, and by device and inode where the folder exists). Kiro data folder per platform, from the collector's source default: macOS `~/Library/Application Support/Kiro`; Windows `%APPDATA%\Kiro` (default `<home>\AppData\Roaming\Kiro`); Linux `$XDG_CONFIG_HOME/Kiro` (default `~/.config/Kiro`). On all platforms also `~/.kiro`, the configured `cyclegauge.sourceRoot`, Cyclegauge's storage (the editor's per-extension global storage, the default storage folder and a configured `cyclegauge.storageRoot`), the editor's data root (three levels above that global storage folder) and its log root, and any folder named `.kiro`, `kiro-cli`, `.aws`, `.ssh` or `.gnupg` at any depth. A final name containing `:` is refused everywhere; on Windows also device names (NUL, CON, PRN, AUX, COM1-9, LPT1-9, with or without an extension) and names ending in a dot or space.

Verification in the implementation worktree: `pnpm typecheck`, `pnpm test`, `pnpm test:release`, `git diff --check`. Unit tests cover the PNG validator (valid, every header field, each chunk corruption, ancillary chunks, CRC, bomb, short image, trailing bytes, split IDAT), the file-target guards (invalid, protected and Kiro-named folders, links, directories, case folding, swap between check and rename, cleanup of the temporary file), CSV formatting, account refusals, conflicts and hostile cells, every recap case, the state validator and visibility rules, `acceptMessage` for the new types with hostile and prototype-key inputs, the panel's in-flight, cooldown and rate limits, the script (reveal, canvas drawing in brand colours at 4.5:1, trusted clicks only, fixed answers, a PNG the validator accepts, hostile models) and the static card markup. Packaged-bundle tests drive the shipped bundle with an invented source: the card, its single `shown` write, copy, dismiss, the unreadable-value case, the support switch for the link, dialog-only saves, refused Kiro, storage and link targets, an invalid image that never opens a dialog, and the multi-account refusal.

Deviations and decisions. **Pending maintainer approval:** a fifth message, `dismissRecap` (no payload), carries the dismiss control, because the approved list had no way to record a dismissal and no extra command link may be added. It only hides the shown recap by writing the dismissed state to `cyclegauge.recap.v1`; `docs/wp6-dashboard-design.md` sections 4.4 and 4.5 name it, marked pending. The card is hidden while the stored value is unknown, so a malformed value cannot show an undismissable card. CSV is also offered when the latest snapshot conflicts or its reset is unknown (the rows say so); it is refused for no data, several or unassociated accounts, bad timestamps and more than 200,000 rows. Status paragraphs use `role="status"` without `aria-live`, keeping the headline the only explicit live region. The brand colours approximate the icon's navy tile and have not been compared with the artwork.

Open: native Kiro acceptance (keyboard, VoiceOver and NVDA reading of the card and its buttons, Trusted Types and `CompressionStream` in the editor's webview, a real canvas export on macOS, Windows and Ubuntu, the save dialog's default folder with localised Downloads names, case-insensitive volumes, junctions on Windows), a fallback for a webview without `CompressionStream` (Save image then reports a failure; Copy text and CSV still work), and the mandatory independent `security-reviewer` review of the file writes, the PNG check and the new key before merge. A re-announced status after a live update is possible because the page restores status text it just replaced.
