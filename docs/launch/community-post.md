I built Bobert, a free unofficial extension for Kiro IDE that warns you before your credits run out ("at this pace they're gone 8 days before the reset") and shows what the overage would cost in dollars, with a plan upgrade comparison. A workspace audit lists large files Kiro may read but probably does not need, with a total size and a ready `.kiroignore` snippet. There's also a dashboard with last-cycle comparison and a shareable cycle recap. It runs entirely locally. The demo GIF uses invented data; feedback and bug reports welcome on GitHub.
