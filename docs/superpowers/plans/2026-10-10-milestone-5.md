# Milestone 5 implementation plan — usage trajectory chart (0.5.0)

Scope source: [visual dashboard proposal](../../milestone-5-visual-dashboard.md), approved 2026-10-10 with three refinements (reported-limit wording, clipped projections, accessible data parity) and a billing-display clarification (usage above the reported limit, e.g. Enterprise `2100 / 2000`; individual prepaid capacity `2100 / 2125`).

## Constraints
- Script-disabled webview, unchanged CSP (`default-src 'none'; style-src 'unsafe-inline'`), no chart library or runtime dependency.
- Collector, Store, Forecast Engine, history and Cost Optimizer algorithms unchanged; presentation only.
- No new data, identifiers or paths in the HTML. No automatic Git commits.

## Tasks
1. **Tests first** (`tests/unit/chart.test.ts`): capacity cases, clipping, data parity, decimation/size, barriers, stale/provisional, safety.
2. **Pure model** (`src/extension/chart-model.ts`): observed points, comparable connectors, unknown periods, events, limit segments, 75%/125% scenario endpoints (exact decimal arithmetic), budget guide, conditional exhaustion, axis range and clipping, bounded decimation.
3. **Renderer** (`src/extension/chart.ts`): inline SVG, theme tokens with forced-colors fallback, line patterns plus marker shapes, HTML legend, text summary and data table.
4. **Integration**: insert the section before Forecast in `present()`; shared `labels.ts`; reported-limit terminology (`Remaining reported capacity`, `Reported credit limit`, `Above reported limit`).
5. **Validation**: full suite, typecheck, fixture validator, responsive/theme checks, VSIX inspection, local Kiro install.

## Decisions
- Scenario factors are fixed at 75%/125% of the selected observed rate; they are not wired to the editable Cost Optimizer factors.
- Budget guide = even allocation of remaining reported capacity from the last observed point to the limit at reset; omitted when none remains.
- A connector is drawn only across comparable intervals of at most 36 hours.
- Optional projected-cost panel and local-time display are deferred.
